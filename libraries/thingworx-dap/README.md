# ThingWorx DeclarativeAnnotationProcessor

`io.github.us-ignite:thingworx-dap` provides DeclarativeAnnotationProcessor annotations and the annotation processor that generates ThingWorx SourceControlEntities XML from Java declarations. It is SDK-independent and is intended for use as an `annotationProcessor` dependency.

The companion [runtime](../thingworx-dap-runtime/README.md) contains InfoTable and typed service result helpers for code running inside ThingWorx.

Use matching versions of the processor and runtime artifacts so generated entity metadata and the
runtime service helpers remain compatible.
