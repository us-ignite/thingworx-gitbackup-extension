# ptcs-mashup-container

## Overview

Web component that behaves as a TWX mashup container. It works under TWX environment only. It invokes TWX code to create mashup.

### Properties

| Property            | Type    | Description                                                                                                                            | Triggers a changed event? |
| ------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| name            | String | Mashup to render                                                                                                     | No                        |
| parameters | Object  | Mashup parameters                                                                | No                        |
