# ThingWorx Kubernetes Operator

An unofficial Java operator for managing a PTC ThingWorx deployment on Kubernetes.
PTC-delivered binaries, licence credentials, customer artefacts, and vendor reference files are not part of this module.

## Build and test

```sh
./gradlew :apps:thingworx-operator:test
./gradlew :apps:thingworx-operator:installDist
./gradlew :apps:thingworx-operator:jibDockerBuild -Pimage=thingworx-operator:dev
./gradlew :apps:thingworx-operator:devSetup
```

`devSetup` builds `thingworx-operator:dev`, then installs or upgrades the chart on the
`docker-desktop` Kubernetes context in the `thingworx-operator` namespace. Override its
target with `-PkubeContext`, `-PkubeNamespace`, `-PhelmRelease`, or `-Pimage=repository:tag`.
It installs only the operator and CRDs by default. Use `-PinstallCluster=true` to apply one
development `ThingWorxCluster` manifest; the operator then creates that cluster's internal
PostgreSQL StatefulSet, Ignite StatefulSet, CXServer Deployment, HAProxy Deployment, and
their Services/configuration in ordered phases. Required referenced Secrets and a valid
ThingWorx license remain operator inputs and are not generated by Gradle.

The operator image definition is in [`../../images/thingworx-operator`](../../images/thingworx-operator/README.md),
and the Helm chart is in [`../../charts/thingworx-operator`](../../charts/thingworx-operator/README.md).

`ThingWorxCluster` resources model the cluster lifecycle. `ThingWorxExtension` resources install digest-pinned
OCI extension artifacts one at a time for each target cluster.
