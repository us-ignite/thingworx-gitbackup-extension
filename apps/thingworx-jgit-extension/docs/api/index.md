# Java API reference

The generated API reference is a **master Javadoc** broken up by classpath — one standalone tree per Gradle project, each with its own dependencies and SDK classpath. Pick the artifact you depend on.

| Gradle project | Artifact | Javadoc |
|---|---|---|
| `:libraries:thingworx-dap` | `io.github.us-ignite:thingworx-dap` | [libraries-thingworx-dap/index.html](javadoc/libraries-thingworx-dap/index.html) |
| `:libraries:thingworx-dap-runtime` | `io.github.us-ignite:thingworx-dap-runtime` | [libraries-thingworx-dap-runtime/index.html](javadoc/libraries-thingworx-dap-runtime/index.html) |
| `:apps:thingworx-jgit-extension` | `com.thingworx:thingworx-jgit-extension` (extension `jar`) | [apps-thingworx-jgit-extension/index.html](javadoc/apps-thingworx-jgit-extension/index.html) |
| `:apps:thingworx-operator` | `io.github.us-ignite:thingworx-operator` | *pending — skipped due to fabric8 API drift; will appear as `javadoc/apps-thingworx-operator/` when build is green* |

* **Master index:** [javadoc/index.html](javadoc/index.html) — links to every per-classpath tree.
* **Legacy single-tree link:** [javadoc/apps-thingworx-jgit-extension/index.html](javadoc/apps-thingworx-jgit-extension/index.html) (kept for backwards compatibility; same as the extension row above).

The reference is generated from the current `main` branch by `./gradlew masterJavadoc` (alias `javadocAll`) and is intended primarily for extension maintainers and integrators troubleshooting service behavior.

> **For maintainers:** Each tree is generated by its own `javadoc` task with its own classpath (`compileClasspath` + SDK + annotation processors). Do not merge sources into one flat tree — keep classpaths separate so consumers see the correct transitive dependencies.

To generate locally:

```bash
./gradlew masterJavadoc
open build/docs/master-javadoc/index.html
# or open the MkDocs preview copy:
open apps/thingworx-jgit-extension/docs/api/javadoc/index.html
```
