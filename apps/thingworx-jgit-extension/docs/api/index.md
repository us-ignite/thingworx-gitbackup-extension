# Java API reference

[Browse the ThingWorx JGit Extension Javadocs](javadoc/index.html).

CI generates this reference from the extension's sources and SDK classpath and
includes it in the documentation site.

To generate the reference locally, run:

```bash
./gradlew :apps:thingworx-jgit-extension:javadoc
```

Open `apps/thingworx-jgit-extension/build/docs/javadoc/index.html` to browse it.
