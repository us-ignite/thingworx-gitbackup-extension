# Mashup sources

`Mashups_GIT.Mashup.Home.xml` lists repository Things and links to Git User
Settings. Selecting a repository opens its operations. It is
the default item in the Git menu. `src/HomeNavigation.ts` is embedded during
packaging by `embedHomeNavigation`.

`Mashups_GIT.Mashup.Changes.xml` provides repository selection, working-tree
status, selected-file stage/unstage/untrack actions, and staged commit. Its
untrack action uses a confirmation dialog. The Git Changes menu item is in
`Menus_GIT.Menu.GitBackup.xml`.

## Operations mashup helper

For the export's XML, embedded JSON, and binding structure, see
[mashup-format-primer.md](../docs/mashup-format-primer.md).
For the widgets, extension dependencies, Java data model, and UI editing
workflow, see [ui-agent-guide.md](../docs/ui-agent-guide.md).

`src/GitHelper.ts` and `src/Operations.css` are the editable sources for the
operations mashup. The `BMTypescriptClassHost` uses ThingWorx binding decorators
and evaluates the generated `TranspiledCode` at runtime. The build embeds the
TypeScript source fields, transpiled JavaScript, and `CustomMashupCss`.

Run `./gradlew :apps:thingworx-jgit-extension:embedGitHelper` to update the
export after editing the source. Packaging the extension runs this task
automatically. The task uses the pinned TypeScript compiler in this directory's
`package-lock.json`; npm and Node.js must be available.

The `src/types` declarations are synchronized from the pinned BMCoreUIWidgets
release ZIP. `tsconfig.json` includes them for editor language services,
including the ThingWorx widget decorators and global types such as `STRING` and
`TWEvent`. Run `./gradlew :apps:thingworx-jgit-extension:syncUiTypeDeclarations`
to refresh them; helper embedding and extension packaging run this task too.

Treat `src/GitHelper.ts` and `src/Operations.css` as the sources of truth. Do
not edit the mashup's `Code`, `Exports`, `TranspiledCode`, or `CustomMashupCss`
fields by hand; those fields are regenerated by the embedding task.

## History mashup

`Mashups_GIT.Mashup.History.xml` uses the standard PTC repository dropdown and
`GitHistoryWidget` to browse commits, changed files, file contents, and diffs.
Build the distribution with `./gradlew :apps:thingworx-jgit-extension:packageExtensionPack`.
The resulting pack contains four independent ThingWorx extension ZIPs. Install
BMCoreUIWidgets, agGridWidget2, and GitHistoryWidget before JGitExtension; the
pack itself is a distribution archive, not a ThingWorx import ZIP. Composer
validation and viewing the mashup on the target ThingWorx version are needed to
verify bindings and layout.
